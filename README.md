# Data Cleaning & Preparation

## Project Overview

This project focuses on cleaning and preparing an e-commerce order dataset using Microsoft Excel.

## Objective

The objective was to identify and handle missing values, check duplicate OrderIDs, validate data formats, and verify calculated values.

## Tools Used

- Microsoft Excel
- Excel Filters
- Conditional Formatting
- Excel Formulas

## Data Cleaning Performed

- Identified missing values in CouponCode
- Replaced blank CouponCode values with "No Coupon"
- Checked OrderID for duplicates
- Validated Date formatting
- Validated Quantity and UnitPrice
- Verified TotalPrice using Quantity × UnitPrice
- Checked categorical/text columns for inconsistencies

## Validation

- Duplicate OrderIDs: 0 found
- Blank CouponCode values after cleaning: 0
- TotalPrice validation: All records OK

## Outcome

The dataset was cleaned and validated and is ready for further analysis.
